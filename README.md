# Performing-Art-Club-make
RANGMANCH — enhanced 2-page Performing Arts Club website

WHAT CHANGED
- Added cinematic performance photography to the Home hero.
- Replaced the emoji-only poster with a full-height theatre photograph.
- Added large photographic cards for Dance, Music, Theatre, Singing and Instrumental.
- Added event thumbnails to the upcoming events list.
- Added a photographic About-page hero and a photo-led gallery.
- Added portrait-style imagery to the sample team cards.
- Updated the gallery lightbox so clicking a gallery tile opens its photograph and caption.
- Preserved the original two-page navigation, mobile menu, event registration modal, join form interactions, counter animation and countdown.

HOW TO RUN
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server (or open index.html directly in a browser).
4. Use the navigation to visit about.html.

FILES
- index.html — Home / Club Dashboard
- about.html — About & Explore
- style.css — layout, visual design, image treatments and responsive rules
- script.js — navigation, forms, registration modal, counters, countdown and gallery lightbox

IMPORTANT BEFORE SUBMISSION
- The images are loaded from Unsplash image URLs, and Google Fonts are loaded online. Internet access is required to display them.
- Review the current Unsplash license/usage terms for each image and follow any attribution requirements applicable to your use.
- Replace all sample event dates, event descriptions, member names, team details, contact information, social links and achievement claims with verified details from your university.
- The sample portraits are illustrative and are not the actual student leaders. Replace them with approved club member photographs.
- The displayed counts (performers, shows, trophies) and team/event history are sample content from the supplied project. Do not submit them as factual unless verified.
- Add your university logo or official club mark if available.

MAKE IT YOUR OWN
This is an enhanced starting point, not a guaranteed competition winner. Personalise the typography, colors, image selection and copy; test on mobile and desktop; and make sure you can explain the HTML structure, CSS grid/flexbox and media queries, JavaScript event listeners, modal, and image lightbox to judges.
